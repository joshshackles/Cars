# Google Play Listing Draft

## App Name

CARS Driver

## Short Description

Daily trip manifest, navigation, GPS mileage, and issue reporting for CARS drivers.

## Full Description

CARS Driver is the mobile companion app for CARS Dispatch volunteer transportation operations. Assigned drivers can securely view their daily manifest, open turn-by-turn navigation, start GPS mileage tracking, mark trip progress, call riders, report issues, and complete trips without manually entering mileage.

The app is intended for authorized drivers working with participating CARS Dispatch organizations. It connects to the CARS Dispatch platform and only shows rides assigned to the signed-in driver.

Key features:

- Daily manifest of assigned rides
- Pickup and dropoff details
- Approved rider notes
- Google Maps route launch
- Foreground GPS mileage tracking
- Start, arrived, and completed trip actions
- Rider call button
- Decline assignment workflow
- Issue reporting to dispatch

Location is used only while a driver is actively tracking an assigned trip, so mileage can be calculated from the trip start to finish.
